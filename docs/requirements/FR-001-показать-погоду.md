# FR-001: Показать погоду по городу

## Описание
Пользователь вводит название города и получает текущую погоду.

## Входные данные
- Название города (текст)

## Выходные данные
- Температура (°C)
- Описание погоды
- Влажность (%)
- Скорость ветра (м/с)

## Сценарий
1. Пользователь вводит "Москва" в поле ввода
2. Нажимает кнопку "Показать погоду"
3. Система отправляет запрос к OpenWeatherMap API
4. Отображает данные на странице

## Критерии приемки
- [ ] Город найден — данные отображаются
- [ ] Город не найден — показывается ошибка
- [ ] Поле пустое — показывается ошибка "Введите название города"
