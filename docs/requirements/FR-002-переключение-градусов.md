# FR-002: Переключение градусов и отображение иконки погоды

## Описание
Пользователь может переключать единицы измерения температуры между Цельсием и Фаренгейтом. По умолчанию отображается Цельсий. При наличии данных от API отображается иконка погодных условий.

## Входные данные
- Действие пользователя: клик по элементу температуры
- Данные от Weather API: температура, код погодного условия (для иконки)

## Выходные данные
- Обновлённое значение температуры в выбранных единицах (°C или °F)
- Иконка погодного условия (если доступна в ответе API)

## Сценарий использования
1. Пользователь открывает карточку погоды (по умолчанию °C)
2. Кликает по значению температуры
3. Система переключает единицы измерения и пересчитывает значение
4. При повторном клике возвращается к исходным единицам
5. Если API вернул код погоды, система отображает соответствующую иконку

## Критерии приемки
- [ ] По умолчанию температура отображается в °C
- [ ] Клик по температуре переключает на °F и обратно
- [ ] Значение корректно пересчитывается по формуле
- [ ] Иконка погоды отображается при наличии данных от API
- [ ] Визуальный индикатор показывает текущие единицы измерения
