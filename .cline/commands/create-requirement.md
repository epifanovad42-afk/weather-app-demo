# Навык: Создание требования (create-requirement)

## Алгоритм
1. Прочитай входящее описание от пользователя.
2. Просканируй папку docs/requirements/ и определи следующий свободный номер FR.
3. Извлеки сущности: Название, Описание, Входные данные, Выходные данные, Сценарий (нумерованный список), Критерии приемки (чек-лист).
4. Создай файл docs/requirements/FR-XXX-название.md.
5. Заполни файл по шаблону ниже.

## Шаблон
# FR-XXX: [Название]

## Описание
[1-2 предложения]

## Входные данные
- [что получает система]

## Выходные данные
- [что возвращает система]

## Сценарий использования
1. [шаг 1]
2. [шаг 2]

## Критерии приемки
- [ ] [критерий 1]
- [ ] [критерий 2]
